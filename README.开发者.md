# README.开发者

## 📋 项目概述

这是一个基于Python开发的货架配置优化工具，旨在通过智能算法为仓储管理人员推荐最优的货架规格组合。程序采用GUI界面设计，集成了多种优化算法，支持装箱装托智能判定，能够最大化存储效率并最小化货架投资成本。

### 核心功能
- **装箱装托智能判定**：基于SKU特性和阈值自动判定存储方案
- **多维度优化算法**：L&D&H三维空间优化
- **精确装箱模拟**：真实模拟SKU在货架上的摆放情况
- **可视化分析**：提供四象限图表分析和诊断报告
- **参数管理系统**：支持参数保存、加载和会话恢复

## 🏗️ 程序架构

```
├── GUI界面模块              # CustomTkinter图形界面

└── 工具函数模块             # 辅助计算函数
```

### 核心模块详解

#### 1. 数据处理模块
- **文件位置**：`read_excel_data()`, `read_shelf_params()`
- **功能**：从Excel读取SKU和货架数据，支持装箱装托双重数据格式
- **关键特性**：
  - 支持预设值填充缺失数据
  - 数据格式验证和清洗
  - 装箱装托LDHWV数据分离处理

#### 2. 装箱装托判定模块
- **文件位置**：`analyze_packing_decision()`
- **功能**：基于Y/N标识和小数阈值自动判定存储策略
- **判定流程**：
  ```
  读取can_box/can_pallet标识 → 
  根据组合判定 → 
  计算装托数小数部分 → 
  应用阈值决策
  ```

#### 3. L&D优化算法模块
- **单一货架算法**：`ld_calculator_single()`
- **互补式算法**：`ld_calculator_complementary()`
- **功能**：寻找最优的长×深规格组合
- **优化目标**：在满足覆盖率的前提下最小化货架数量

#### 4. H高度优化算法模块
- **三维评分体系**：`h_calculator_three_dimensional()` - 推荐算法
- **边界效应算法**：`h_calculator_boundary_driven()`
- **手动百分位算法**：`h_calculator_coverage_driven()`
- **核心逻辑**：基于不同策略寻找最优高度组合

#### 5. 精确装箱模块
- **混合模式**：`final_placement_with_individual_skus_mixed()`
- **标准模式**：`final_placement_with_individual_skus()`
- **装箱算法**：FFD (First Fit Decreasing) 算法
- **功能**：精确计算货架需求数量和SKU分配

#### 6. GUI界面模块
- **主框架**：CustomTkinter应用
- **参数配置区**：左侧滚动框架，包含所有配置项
- **结果展示区**：右侧标签页，包含日志和图表
- **参数管理**：支持保存/加载/默认配置管理

#### 7. 可视化模块
- **四象限图表**：
  1. 方案总览（货架规格和数量）
  2. 决策依据（SKU分布散点图）
  3. SKU诊断（安置情况饼图）
  4. 货架剖面图（装箱效果展示）

## 🛠️ 维护指南

### 代码维护要点

1. **线程安全**
   - GUI和计算逻辑分离运行
   - 使用Queue进行线程间通信
   - 注意GUI更新必须在主线程

2. **参数管理**
   - 参数自动保存机制在`auto_save_session()`
   - 参数验证逻辑在`collect_params()`
   - 默认配置文件：shelf_optimizer_config.json

3. **缓存机制**
   - 文件读取结果缓存，避免重复IO
   - 聚合数据缓存，提升重复计算速度
   - 缓存失效条件：文件路径或Sheet名称变化

4. **错误处理**
   - 所有用户输入都有验证
   - 计算过程异常会回滚到安全状态
   - 错误信息会显示在GUI日志区

### 调试建议

1. **日志系统**
   - 使用`q.put(("log", message))`添加日志
   - 进度更新：`q.put(("progress", (current, total, start_time, description)))`

2. **性能监控**
   - 计算密集型函数已添加进度报告
   - 可通过修改`NUM_BINS_FOR_AGGREGATION`调整聚合粒度

3. **参数调优**
   - 覆盖率目标建议85%-95%
   - 高度步长影响计算精度和速度
   - 互补性阈值影响L&D算法结果

## 🔍 代码热点分析

### 性能瓶颈点
1. **`ld_calculator_complementary()`** - 组合算法复杂度过高
2. **`final_placement_with_individual_skus_mixed()`** - 精确装箱计算耗时
3. **GUI更新频率** - 进度更新过于频繁导致界面卡顿

### 关键决策点
1. **装箱装托判定阈值** - 影响最终方案的核心参数
2. **聚合粒度控制** - 平衡计算精度和性能
3. **缓存策略** - 决定重复计算的性能表现

### 扩展接口
1. **算法接口**：`ld_calculator_*()`, `h_calculator_*()`
