# README.用户端

## 🎯 程序概述

这是一款专业的仓储货架配置优化工具，旨在帮助仓储管理人员根据SKU（库存单位）特性，自动推荐最优的货架规格组合，最大化存储效率并最小化货架投资成本。

### 🌟 核心功能
- **智能装箱装托判定**：根据SKU特性自动判定装箱、装托或混装方案
- **多维度优化算法**：综合考虑L（长度）、D（深度）、H（高度）三个维度
- **精确装箱模拟**：真实模拟SKU在货架上的摆放情况
- **可视化分析**：提供直观的图表分析和诊断报告

---

## 📋 使用流程

### 第一步：准备数据文件
1. 准备一个Excel文件，包含两个Sheet：
   - **SKU数据Sheet**：包含所有库存单位的详细信息
   - **货架数据Sheet**：包含可选的货架规格信息

### 第二步：配置参数
1. 点击"选择Excel文件"按钮选择数据文件
2. 在左侧面板中配置各项参数（详见参数说明）
3. 根据需要调整算法参数

### 第三步：运行计算
1. 点击"开始计算"按钮启动优化算法
2. 在"运行日志"标签页查看计算进度
3. 计算完成后在"分析图表"标签页查看可视化结果

### 第四步：查看结果
- 程序会自动生成带有结果的Excel文件
- 查看推荐的货架规格和数量
- 分析未安放SKU的原因

## 📊 参数配置说明

### 🏢 基础配置

#### Sheet名称
- **SKU数据的Sheet名**：包含SKU信息的Excel工作表名称
- **货架数据的Sheet名**：包含货架规格的Excel工作表名称

### 📦 装箱装托配置

#### 基础判定列
- **可装箱列名(Y/N)**：标识SKU是否可以装箱存储的列名
- **可装托列名(Y/N)**：标识SKU是否可以装托存储的列名
- **装箱数列名**：每个SKU需要的装箱数量
- **装托数列名**：每个SKU需要的装托数量
- **单托箱数列名**：每个托盘可装多少箱的数量

#### 货架类型配置
- **货架类型标识列名**：货架数据中区分货架类型的列名
- **装托标识字符**：用于标识装托货架的字符（如"A"）
- **装箱标识字符**：用于标识装箱货架的字符（如"B"）
- **装托小数阈值**：当装托数的小数部分超过此值时，采用纯装托策略（推荐0.3）

### 📏 核心参数

- **覆盖率目标(%)**：算法要达到的SKU覆盖率目标，推荐90%
- **最大允许高度(mm)**：超过此高度的SKU将被过滤掉
- **允许SKU旋转90°放置**：是否允许将SKU旋转90度来适应货架

### 🔧 算法配置

#### L&D计算方法
- **单一货架算法**：寻找一种最优的长×深规格，生成2种最终规格（配合2个高度）
- **两种货架算法（互补式）**：寻找两种互补的长×深规格，生成4种最终规格
  - *互补性-面积比例阈值*：两种货架底面积相似程度要求（0-1，越大要求越相似）
  - *互补性-尺寸比例阈值*：两种货架长深尺寸相似程度要求（0-1，越大要求越相似）

#### H高度计算方法
1. **三维评分体系算法（推荐）**：
   - *高度步长*：高度搜索的精度，越小越精确但耗时更长
   - *最小高度差值*：确保两种货架高度有明显区别的最小差值
   - *数量/体积/高度利用率权重*：调整三个维度在综合评分中的重要性
   - *最低数量利用率阈值*：方案必须达到的最低SKU数量覆盖率

2. **边界效应算法**：
   - 通过分析SKU高度分布的边界效应来确定最优高度组合
   - *体积权重系数α*：平衡SKU数量和体积的重要性（0-1）

3. **手动百分位算法**：
   - 直接指定两个百分位点作为高度规格

### 🏭 仓库环境参数

- **仓库总高度(mm)**：仓库的总高度限制
- **底层离地高度(mm)**：最底层货架离地面的高度
- **每层预留空间(mm)**：每层货架之间的预留空间
- **货架层板厚度(mm)**：货架层板的厚度

### 📋 数据列名配置

#### 货架LDW列名
- **货架长度列名(Lp)**：货架长度数据的列名
- **货架深度列名(Dp)**：货架深度数据的列名
- **货架承重列名(Wp)**：货架承重限制的列名

#### 装托LDHWV列名
- **SKU编号**：SKU唯一标识符的列名
- **装托长度/深度/高度(L/D/H)**：SKU装托模式下的尺寸列名
- **装托重量/体积(W/V)**：SKU装托模式下的重量和体积列名

#### 装箱LDHWV列名
- **装箱长度/深度/高度/重量/体积**：SKU装箱模式下的各项参数列名

#### 预设值配置
当SKU数据中缺少某些LDHWV参数时，系统将使用这些预设值进行填充。

## 🎨 结果解读

### 📈 分析图表
1. **方案总览**：显示推荐的货架规格和各自需要的数量
2. **决策依据**：SKU尺寸分布散点图，叠加推荐的货架规格
3. **SKU诊断**：显示成功安放和未安放SKU的比例及原因
4. **装箱效果**：单个货架的真实装箱效果剖面图

### 📄 输出文件
程序自动生成Excel结果文件，包含：
- **[安放状态]**：每个SKU是否成功安放
- **[未安放原因]**：未安放SKU的具体原因
- **[货架规格]**：成功安放SKU所使用的货架规格

## 💡 使用建议

### 🎯 参数调优建议
1. **覆盖率目标**：建议设置为85-95%，过高可能导致过度投资
2. **装托小数阈值**：0.3是一个平衡点，可根据实际业务调整
3. **高度步长**：在精度和计算时间之间找平衡，建议10-50mm

### ⚠️ 注意事项
1. 确保Excel文件中的数据格式正确，数值列不包含文本
2. Y/N列必须只包含"Y"或"N"字符（不区分大小写）
3. 建议在小数据集上先测试参数配置，再用于大规模计算
4. 程序会自动保存参数配置，下次启动时自动恢复

### 🚀 高级功能
- **右键菜单**：在按钮区域右键可访问参数管理功能
- **参数保存/加载**：可保存常用参数配置供后续使用
- **会话恢复**：程序自动记住上次使用的参数设置

## 📞 技术支持

如遇到问题，请检查：
1. Excel文件格式和数据完整性
2. 列名配置是否与实际Excel列名匹配
3. 数值参数是否在合理范围内
